# دفتر الحسابات

تطبيق ويب للموبايل لإدارة شجرة حسابات (درج، محافظ، انستا، مكن، عملاء) مع تحويلات بين كل الحسابات، أرباح وخسائر، ليمت للمحافظ، صلاحية الخط، عمليات معلقة، تسويات يومية وشهرية، ومبيعات اكسسوار. بدون سيرفر، والبيانات تُحفظ في `localStorage` على جهازك.

## الملفات
- `index.html` الهيكل
- `style.css` التصميم
- `script.js` المنطق وحفظ البيانات

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة، أو من داخل المجلد: `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub وارفع الملفات الأربعة (بدون مجلد داخلي).
2. من Settings ثم Pages اختر Branch: main وFolder: /root ثم Save.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظات
- البيانات خاصة بكل جهاز ومتصفح ورابط. استخدم "نسخة احتياطية" من تبويب المزيد قبل تغيير الرابط أو مسح بيانات المتصفح.
